# EZ-Template-Corpus

This is a list of public GitHub projects that use [EZ-Template](https://github.com/EZ-Robotics/EZ-Template). The EZ-Template maintainers use it to find bugs and to see how teams use the library.

## What we do with your code

The list in [`corpus.csv`](corpus.csv) is only links. We don't copy or share anyone's code. We just read public projects to learn from them.

If your project helps us find a bug in EZ-Template, we write our own test for it. The EZ-Template issue or commit will say the bug was found in the EZ-Template-Corpus, without naming or linking your project.

## Taking your project off

Add an empty file named `.ez-corpus-optout` to the top folder of your repo. Your project comes off at the next update and stays off.

If you'd rather ask, or you want everything in your account or org taken off, message a maintainer on the [robotics is ez Discord](https://discord.gg/EHjXBcK2Gy) or email [jess@roboticsisez.com](mailto:jess@roboticsisez.com). A repo that goes private or gets deleted comes off the list by itself.

## Updates

The list updates itself every other Monday. It drops projects that went private, were deleted, or opted out, and it searches GitHub for new ones.
