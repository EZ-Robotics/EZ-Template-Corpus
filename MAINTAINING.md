# Maintaining EZ-Template-Corpus

The list updates itself every other Monday. The only thing you need to do is take a project off when someone asks.

## Taking a project off

1. Go to the repo's **Actions** tab.
2. Click **Remove a project** on the left.
3. Click **Run workflow**, paste the link to the project, and click the green **Run workflow** button.

The project and its forks come off the list and stay off. If you paste a link to an account or org instead, everything it owns comes off.

If the request came in as a GitHub issue, ask a repo admin to delete the issue afterward, since it names the project.

To put a project back, only when the owner asks, do the same thing and tick **Put it back instead**.

## Using the corpus

Don't copy or quote a team's code, in this repo or in EZ-Template issues, pull requests, or commits. If a team's code shows you an EZ-Template bug, write our own test for it, and say the bug was found in the EZ-Template-Corpus without naming or linking the project.
